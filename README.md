# 少喝一点点

一个给本人使用的戒酒/减量与健康习惯打卡器。它是纯静态网页，不需要登录、不上传数据，记录只保存在当前浏览器的 `localStorage` 中。

## 使用方式

直接用浏览器打开 `index.html` 即可使用。

功能包括：

- 今日三档打卡：没喝、少量、超量
- 今日运动打卡：没运动、轻微活动、完成运动
- 今日甜食打卡：没吃、少量、吃多了
- 今日心情和诱因记录
- 连续改善天数、最近 7 天饮酒/运动/少甜趋势、最近 30 天日历
- 清空本地数据

## 安全说明

这个工具只用于日常记录和支持，不能替代医生、心理咨询师或成瘾治疗服务。长期大量饮酒者不建议突然硬停；如果出现明显手抖、出汗、心慌、意识混乱、抽搐等情况，请及时联系医生或急救服务。

参考方向来自公开健康资料：酒精使用障碍是可治疗的健康问题，行为支持、互助支持和必要时的药物治疗都可能有帮助。

- NIAAA Alcohol Treatment Navigator: https://alcoholtreatment.niaaa.nih.gov/
- CDC Alcohol and Public Health: https://www.cdc.gov/alcohol/
- SAMHSA National Helpline: https://www.samhsa.gov/find-help/national-helpline
